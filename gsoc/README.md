# Alpha One Labs - Google Summer of Code 2027

This directory contains the Alpha One Labs GSoC site, including the project
ideas, contributor leaderboard, and static deployment configuration.

## Live site

The site is deployed at [https://gsoc.alphaonelabs.com](https://gsoc.alphaonelabs.com).

## Local development

From the repository root:

```bash
cd gsoc
python3 -m http.server 8000
```

Visit `http://localhost:8000`.

## Editing project ideas

The current project ideas are maintained in Markdown:

- `ideas/2027.md` contains the current ideas.
- `ideas/*.md` files are the source files for the ideas page.
- `ideas.html` is generated from those Markdown files; edit the Markdown rather
  than editing `ideas.html` directly.

After editing or adding a current ideas file, rebuild `ideas.html`:

```bash
cd gsoc
pip install markdown
python scripts/build_ideas.py
```

The archive files remain separate so historical ideas stay available on the
site.

## Generating the leaderboard

The leaderboard is generated by `scripts/generate_leaderboard.py`.

Run it from the `gsoc` directory:

```bash
cd gsoc
export GITHUB_TOKEN="your-token"
python scripts/generate_leaderboard.py
```

On Windows PowerShell, set the token with:

```powershell
$env:GITHUB_TOKEN="your-token"
python scripts/generate_leaderboard.py
```

`GITHUB_TOKEN` is used to authenticate GitHub API requests and avoid low
unauthenticated API limits. A token is recommended for local generation and is
configured automatically in the deployment workflow.

The script writes contributor data to `data/leaderboard.json`. Legacy merged
pull request counts that can no longer be discovered through GitHub search are
maintained in `data/legacy-merges.json`.

## Tests

Run the leaderboard unit tests from the `gsoc` directory:

```bash
cd gsoc
python -m pytest -q
```

The tests are offline and do not call the GitHub API.

## Deployment

The GSoC site uses Wrangler static assets. Its Cloudflare configuration is in
`wrangler.toml`, with the site assets served from the `gsoc` directory.

There are two deployment paths:

- `.github/workflows/deploy-sites.yml` builds and deploys `gsoc` when files
  in this directory change on `main`.
- `.github/workflows/gsoc-leaderboard.yml` regenerates the ideas and
  leaderboard and deploys the site every six hours or when triggered manually.

Both workflows use Wrangler to deploy the static site to
`gsoc.alphaonelabs.com`.

## Technology

- HTML and CSS
- Python scripts for ideas and leaderboard generation
- Cloudflare Workers static assets through Wrangler
- GitHub Actions for scheduled generation and deployment
